# Duinvoetjes

Brosse buitenkant met een taaie (*chewy*) amandelkern op basis van amandelmeel, kristalsuiker,
witte basterdsuiker en vloeibaar eiwit, half gedipt in getempereerde pure chocolade.

## Formule

| Ingrediënt | Gewicht (g) | Schaling (%) | Batch (%) | Opmerking |
| :--- | ---: | ---: | ---: | :--- |
| **Droge fase** | | | | |
| **Amandelmeel** | 200.0 | 100.0% | 35.0% | fijn, gezeefd |
| Kristalsuiker | 100.0 | 50.0% | 17.5% | fijne korrel, voor de kraak aan de buitenzijde |
| Witte basterdsuiker | 100.0 | 50.0% | 17.5% | voor vochtretentie in de kern |
| Fijn zeezout | 1.0 | 0.50% | 0.18% | |
| **Hydratatie** | | | | |
| Eiwit | 70.0 | 35.0% | 12.3% | vloeibaar, niet opgeklopt |
| **Afwerking** | | | | |
| Pure chocolade 70% | 100.0 | 50.0% | 17.5% | getempereerd, om te dippen |
| **Totaal (inzet)** | **571.0** | **285.5%** | **100.0%** | |

_Schaling: % van Amandelmeel, 200.0 g. Batch: % van de totale inzet, 571.0 g._

## Bereiding

### Droge fase

| Ingrediënt | Gewicht (g) | Opmerking |
| :--- | ---: | :--- |
| Amandelmeel | 200.0 | fijn, gezeefd |
| Kristalsuiker | 100.0 | fijne korrel, voor de kraak aan de buitenzijde |
| Witte basterdsuiker | 100.0 | voor vochtretentie in de kern |
| Fijn zeezout | 1.0 | |
<!-- /culinaria:phase -->

1. Meng het amandelmeel met de kristalsuiker, de witte basterdsuiker en het zeezout. Wrijf
   eventuele klontjes in de basterdsuiker volledig los.

### Hydratatie

<!-- culinaria:phase (generated - edits here are overwritten) -->
| Ingrediënt | Gewicht (g) | Opmerking |
| :--- | ---: | :--- |
| Eiwit | 70.0 | vloeibaar, niet opgeklopt |
<!-- /culinaria:phase -->

2. Voeg het vloeibare, onopgeklopte eiwit toe en meng met een spatel tot een stevige, plakkerige
   pasta. Laat 15-30 minuten rusten.

   _Waarom:_ tijdens de korte rust lost een deel van de suiker en invertsuiker op in het eiwitwater.

### Bakken

3. Verwarm de oven voor op 170 °C. Rol met licht bevochtigde handen bolletjes van 20 g en leg ze
   op een met bakpapier beklede bakplaat.
4. Bak 12-14 minuten op 170 °C tot de koekjes nog bleek zijn met slechts een licht goudbruin
   randje.
5. Laat volledig afkoelen op de plaat; de koekjes zijn warm zeer zacht en winnen hun taaie beet pas
   bij afkoeling.

### Afwerking

<!-- culinaria:phase (generated - edits here are overwritten) -->
| Ingrediënt | Gewicht (g) | Opmerking |
| :--- | ---: | :--- |
| Pure chocolade 70% | 100.0 | getempereerd, om te dippen |
<!-- /culinaria:phase -->

6. Doop de afgekoelde duinvoetjes voor de helft in de getempereerde pure chocolade en laat op
   bakpapier uitkristalliseren.

## Notities

- Mogelijke variatie voor een vervolgproef: vervang de witte basterdsuiker door extra kristalsuiker
  en een deel poedersuiker.
