# Pannenkoekenmix hartig (actieve mout)

Droge pannenkoekenmix met patentbloem, boekweitmeel, volkoren tarwebloem, actief gerstemoutmeel en
ascorbinezuur voor sterke Maillardbruining en gecontroleerde beslagviscositeit.

## Formule

| Ingrediënt | Gewicht (g) | Schaling (%) | Batch (%) | Opmerking |
| :--- | ---: | ---: | ---: | :--- |
| **Premix** | | | | |
| Ascorbinezuur | 0.1 | 0.015% | 0.010% | afwegen op 0.01 g precisieweegschaal |
| Actief gerstemoutmeel | 10.0 | 1.5% | 0.97% | |
| Fijn zeezout | 18.0 | 2.8% | 1.8% | |
| **Patentbloem** | 50.0 | 7.7% | 4.9% | draagfractie voor de premix |
| **Hoofdmix** | | | | |
| **Patentbloem** | 600.0 | 92.3% | 58.4% | resterende deel (11-12% eiwit) |
| Boekweitmeel | 200.0 | 30.8% | 19.5% | |
| Volkoren tarwebloem | 150.0 | 23.1% | 14.6% | |
| **Totaal (inzet)** | **1028.1** | **158.2%** | **100.0%** | |

_Schaling: % van Patentbloem, 650.0 g. Batch: % van de totale inzet, 1028.1 g._

### Premix

1. Weeg het ascorbinezuur af op een precisieweegschaal en meng het samen met
   het actieve gerstemoutmeel en het zeezout grondig door het eerste deel patentbloem.

   _Waarom:_ deze verdunningsstap voorkomt lokale overconcentraties (hotspots) die het
   glutennetwerk later ongelijkmatig zouden oxideren of hydrolyseren.

2. Voeg de premix toe aan de resterende patentbloem, het boekweitmeel en de volkoren tarwebloem.
3. Zeef het geheel minimaal tweemaal door een fijne zeef en bewaar droog en luchtdicht.

## Notities

- **Gebruik als beslag:** hydrateer de droge mix met eieren en halfvolle melk (20-25 °C) tot
  roomdikte en laat 45 minuten rusten bij ~21 °C zodat $\alpha$- en $\beta$-amylasen beschadigd
  zetmeel naar maltose omzetten en proteasen de viscositeit verlagen. Bak in gietijzer of
  koolstofstaal op 175 °C.
