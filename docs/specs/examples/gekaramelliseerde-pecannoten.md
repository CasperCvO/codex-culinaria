# Gekaramelliseerde pecannoten

Geroosterde pecannoten met een dunne, glasachtige laag droge karamel (hard crack). Luchtdicht
houdbaar tot het draaien van het ijs.

## Formule

| Ingrediënt | Gewicht (g) | Schaling (%) | Batch (%) | Opmerking |
| :--- | ---: | ---: | ---: | :--- |
| **Roosteren** | | | | |
| **Pecannoten** | 80.0 | 100.0% | 57.1% | ongezouten, halve noten |
| **Karamel** | | | | |
| Kristalsuiker | 60.0 | 75.0% | 42.9% | voor de droge karamel |
| **Totaal (inzet)** | **140.0** | **175.0%** | **100.0%** | |

_Schaling: % van Pecannoten, 80.0 g. Batch: % van de totale inzet, 140.0 g._

## Bereiding

### Roosteren

<!-- culinaria:phase (generated - edits here are overwritten) -->
| Ingrediënt | Gewicht (g) | Opmerking |
| :--- | ---: | :--- |
| Pecannoten | 80.0 | ongezouten, halve noten |
<!-- /culinaria:phase -->

1. Verwarm de oven voor op 160 °C en rooster de pecannoten in 8 minuten goudbruin en geurig.
   Laat afkoelen en hak grof.

### Karamel

<!-- culinaria:phase (generated - edits here are overwritten) -->
| Ingrediënt | Gewicht (g) | Opmerking |
| :--- | ---: | :--- |
| Kristalsuiker | 60.0 | voor de droge karamel |
<!-- /culinaria:phase -->

2. Smelt de kristalsuiker droog in een steelpan met een dikke bodem op middelhoog vuur. Beweeg
   de pan af en toe maar roer niet met een lepel, om kristallisatie te voorkomen.
3. Laat de suiker smelten tot een diepe, amberkleurige karamel (155-160 °C).
4. Stort de geroosterde pecannoten direct in de hete karamel en schep ze met een
   hittebestendige spatel vliegensvlug om tot alle noten met een dunne, glasachtige laag
   karamel bedekt zijn.
5. Stort de noten direct uit op een siliconen bakmat of een vel bakpapier en trek ze met twee
   vorken los van elkaar voordat de karamel hard wordt.
6. Laat volledig afkoelen en bewaar luchtdicht tot gebruik.
